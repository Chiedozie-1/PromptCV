Cookie Preferences

This page explains the cookies and similar technologies used by the PromptCV public website. It also tells you how to revisit your choices if optional cookie categories are introduced.

CURRENT STATUS

No optional preferences to manage

The public website code does not currently configure optional preference, analytics, performance, or advertising cookies or trackers. There is no optional category to accept or reject, and this page does not save a preference or consent timestamp.

If optional technologies are added, this page and any relevant notice will be updated with the categories, controls, and storage behaviour before they are used.

Strictly necessary technologies

Technologies needed to deliver a page you request, protect the service, or support essential routing may operate without an optional preference where applicable law permits. The public website code does not set a first-party cookie for preferences. Hosting or security infrastructure may use its own strictly necessary mechanisms; those are controlled by the relevant provider.

We do not offer a switch to disable a technology that is necessary to deliver a requested page or protect the service.

Optional categories

No optional cookie categories are currently configured on this public website. In particular, its code does not include a configured analytics or advertising tracker. As a result, this page intentionally has no inactive toggles or accept, reject, or save buttons that would not change how the site works.

External website resources

Some pages load font files from Google Fonts and stylesheet files from jsDelivr. A request for those files is sent to the provider when a page uses them. These static-resource requests are not described here as optional tracking cookies; the providers' own privacy information applies to their services.

This page covers the PromptCV public website, not the separate application or other third-party sites reached through links. Their technologies and choices may differ.

Changing preferences later

There are no optional preferences saved for this site at present. If optional technologies are introduced, you will be able to make an informed choice here and return using the persistent Cookie Preferences link in the site footer.

Related information

For information about the waitlist and personal information described in the current notice, read the Privacy Policy. The Terms of Service are a separate draft and do not replace the Privacy Policy.
