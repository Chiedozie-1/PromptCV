No website traffic numbers are shown until a privacy-conscious analytics provider is configured. Waitlist signups are measured from Supabase, but they are not a substitute for visitors or sessions.

Suggested setup: Plausible Analytics
Create a PromptCV site in Plausible, add its lightweight script to the public pages, then connect the Plausible API key and site domain in Vercel server-side environment variables. Define the reporting timezone and compare visitors, sessions, and page views over the same date range. Do not expose the API key in browser code.
